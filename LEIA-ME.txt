ROTINA DA FAMÍLIA — PWA DE TESTE

Versão sem login, preparada para testes com amigos.

- Cada aparelho/navegador mantém seus próprios dados.
- Nenhuma criança é cadastrada inicialmente.
- O usuário cadastra a primeira criança.
- Missões, comportamentos, recompensas, medalhas e histórico.
- Navegação por data e histórico recolhível.
- Backup/restauração JSON.
- Instalação como PWA.
- Cache para funcionamento offline após o primeiro acesso.

Publicação:
1. Envie todos os arquivos para a raiz do repositório GitHub.
2. Ative GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
3. Abra a URL no celular e escolha Instalar aplicativo / Adicionar à tela inicial.

Importante: os dados não ficam no GitHub. Para sincronizar uma família em vários celulares será necessária uma futura versão com nuvem/login.
